# Effects

We have a bunch of built in post processing effects.

## [Tonemapping](/rendering/post-processing/effects/tonemapping.md)

Remaps HDR colours for display. Multiple operators, plus auto exposure.

## [FilmGrain](/rendering/post-processing/effects/filmgrain.md)

Adds simulated film-style grain to the camera output.
