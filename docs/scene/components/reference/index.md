# Reference

Reference documentation for some of the built-in components.

## [Player Controller](/scene/components/reference/player-controller.md)

A first and third person player controller that works with no code.

## [Camera Effects](/scene/components/reference/camera-effects.md)

Shake, punch and tilt on a camera, plus `EnvShake` and custom camera modifiers.

## [Hammer Mesh](/scene/components/reference/hammer-mesh.md)

The component created for meshes tied to a GameObject in Hammer.

## [TemporaryEffect](/scene/components/reference/temporaryeffect.md)

Deletes its GameObject once its particles and sounds have finished.
